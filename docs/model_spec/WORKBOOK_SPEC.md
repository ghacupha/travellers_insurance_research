# Travelers P&C workbook specification, version 1

This is the formula and presentation contract for the evolving workbook, not a completed integrated model or certified history. It defines an independent US GAAP property and casualty model using common financial-modeling conventions. The third-party teaching workbook previously used as a layout reference is not distributed with this repository, and no workbook copy is required to build or run the insurance model. The source ledger is `examples/travelers/source_inventory.json`; `HISTORICAL_COVERAGE.md` and `historical_coverage.json` record extraction status at a 2026-02-12 information cutoff. Fiscal 2025 ends on 2025-12-31, which is distinct from the date on which the information became public. The current [workbook status](WORKBOOK_STATUS.md) describes the first generated operating model and its limits.

## Periods, scope and lineage

The `Model` sheet holds 2019 opening *balance* inputs in G, six annual actual columns H:M (2020–2025), and five formula forecast columns N:R (2026–2030). All periods are calendar fiscal years. The 2019 column must never contain a fabricated 2019 flow. Forecast year one refers to M for opening balances. The generated `workbook_contract.json` is a broad semantic metric inventory and preliminary row plan; `rendered_row_map.json` is the versioned physical map of the first generated workbook. Do not copy positions from the three-actual reference workbook.

The consolidated model uses USD millions unless the row declares fractions or million shares. Source ingestion preserves the source's original scale, sign, accounting basis, entity/segment, dates, and locator. Currency conversion or restatement is an explicit transformation with its own source and calculation record. A zero is a number; missing is a separate state. Every historical hardcode on `Model` links to a `Sources` ledger entry containing source ID, URL, filing date, PDF page, original value and status; retrieval date and exact SEC table/tag remain later ledger enhancements. A source PDF being indexed does not establish that a given metric is disclosed. The current workbook retains provisional PDF-copy status for rows not yet matched to original SEC HTML; such rows cannot support an approved price target.

Consolidated P&C is the first numeric block. Requested segment blocks cover Business Insurance, Bond & Specialty Insurance, and Personal Insurance only where the issuer discloses the particular metric and basis. A corporate/reconciliation block bridges disclosed segment sums to consolidated; do not allocate missing segment cash, reserves or investments by premium share. Record classification changes and held-for-sale movements separately. The company-specific ratio bridge is isolated from the generic P&C engine.

## Tabs and modelling conventions

| Tab | Required content |
|---|---|
| Cover | Issuer, model scope, accounting basis, fiscal periods, as-of date, run ID, status, version and source caveats. |
| Summary | KPI trend, underwriting/portfolio/capital/valuation outputs, scenario comparison, and a visible Master Check. Only validated outputs are promoted. |
| Assumptions | Dated scenario drivers by segment, premiums, loss, payout, expenses, reinvestment, capital, tax and valuation. Distinguish sourced benchmark, analyst judgment and modeled proxy. |
| Scenarios | One live scenario selector at `D6` (base/upside/downside) plus clearly labeled frozen comparison snapshots with run ID and timestamp. Changing the selector recalculates live model formulas; snapshots update only when Python reruns. |
| Model | Vertical P&C operating schedules first, then integrated statements and checks. G opening; H:M actual; N:R forecast; period and unit headings frozen. |
| Output | Sourced market inputs, insurer valuation methods, sensitivity and research-ready tables; no price target while checks remain unresolved. |
| Sources | Per-fact provenance, transformation, cutoff eligibility, source precision and unresolved items; link to immutable cache hashes. |

Use restrained vertical sections, adjacent period columns, centralized assumptions, a scenario selector, live Summary links and displayed checks. Historical disclosed inputs use blue font; same-sheet calculations black; cross-sheet references teal/green; analyst assumptions and proxies orange with a legend. Formula status is more important than color: `Sources` should distinguish disclosed, derived, modeled and missing. Forecast columns have a distinct header and border; formulas must be copy-safe and not hardcode 2025 as a row-specific string. Errors, unresolved data and stale snapshots are visible; checks turn red on failure. A `CHOOSE`-driven scenario pattern is acceptable if the selected drivers truly propagate through reserves, investments, statements and valuation.

Use readable print areas with repeated period headings and section-level landscape pages. Eleven annual columns plus labels should be visually inspected at print scale; split print panels if needed instead of shrinking type below readability. Freeze the label and period header area. The insurance workbook uses `Cover`, `Summary`, `Assumptions`, `Scenarios`, `Model`, `Output` and `Sources`.

## Schedule dependencies and formula rules

The contract reserves semantic rows, not final Excel formulas. Each equation below applies to a consistent segment and gross/net basis. Signed prior-year development is negative when favorable; positive ceded premiums and paid claims are presented as positive amounts then subtracted in bridges.

| Stage | Historical calculation and forecast driver | Required check |
|---|---|---|
| Premium | `GWP = direct + assumed written`; `NWP = GWP − ceded written`. Earned on each gross/ceded basis = written + opening UPR − closing UPR + explicit FX/transfer/other earning movements. `NEP = gross earned − ceded earned`. The balance-sheet UPR liability is gross; ceded UPR is a separate asset; `net UPR = gross UPR − ceded UPR` on comparable bases. Forecast exposures/price/mix or explicitly modeled growth, retention and earning pattern by segment. | Gross/net written and earned bridges; net UPR movement; segment to consolidated. |
| Claims/reserves | `net P&C reserve = gross P&C reserve − recoverables on unpaid P&C claims`. `total rollforward incurred = current accident-year incurred + signed prior accident-year adjustment`; `closing net reserve = opening net + incurred − paid current − paid prior + explicit FX/acquisition/transfer/other`. Catastrophe losses are within incurred, not an added expense. Forecast attritional/catastrophe claims, reserve development and payout timing. | Reserve rollforward, gross/net unpaid recovery bridge, source reserve table and presentation bridge. |
| Reinsurance | Keep recoverables on unpaid claims, paid claims, prepaid premiums, allowance and collected cash as separate objects. Never offset total balance-sheet recoverables against gross unpaid reserves. Held-for-sale reserves and recoverables get explicit presentation adjustments. | Reserve-table unpaid recovery to balance-sheet reinsurance asset bridge; collected cash where disclosed. |
| Expense/DAC | Opening DAC + additions − amortization + FX/transfer/other = closing DAC. Separate GAAP claims and G&A, policyholder dividends and Travelers' fee allocation bridge. Loss ratio and expense ratio use documented issuer numerators over NEP; combined is their sum at calculation precision. Underlying ratio removes catastrophe and development using the issuer definition. | DAC rollforward; reported ratio bridge within source display precision; GAAP to underwriting expenses. |
| Investments | Opening holdings by asset class + purchases − carrying value of sales/maturities + amortization/fair value/FX/other = closing holdings. Net investment income, realized gain/loss and after-tax OCI are separate. Yield is net investment income divided by a defined average invested-asset base, with asset/time basis documented. Forecast opening holdings, maturity/reinvestment, rate, cash needs and duration. | Asset class to balance sheet, investment movement, income/yield and cash-flow purchases/proceeds. |
| Tax/debt/equity | Separate current/deferred tax and paid taxes, debt issuance/repayment/interest. Opening common equity + net income + OCI − dividends − buybacks + issuance/compensation + disclosed other = closing equity. Period-end shares differ from diluted weighted-average shares. Statutory surplus remains a separately scoped regulatory measure. | Debt, tax and equity movements; EPS/share basis; no GAAP/statutory conflation. |
| Statements | Operating schedules feed the income statement, then cash movements and balance sheet. CFO + CFI + CFF + FX/reclassification = cash movement on the same restricted-cash basis. Insurance receivables/liabilities, DAC, investments and reinsurance assets map to their own balance-sheet lines. | Assets − liabilities − equity = 0; cash-flow opening/closing; net income, premiums, reserve, DAC, investments and equity tie to schedules. |

The reserve-table prior accident-year adjustment and the reported favorable prior-year development used in the underwriting ratio are **different measures**. For example, FY2025's annual report reserve table shows a signed −$939m adjustment, while the issuer release reports $1,036m favorable development. Discount accretion and other scope/timing items require an evidenced reconciliation; the renderer must not silently equate the two. FY2025 reserve-table gross P&C reserves and the consolidated balance-sheet reserve line also require a held-for-sale/other-insurance presentation bridge. These are specification examples, not certified imported actuals.

## Valuation and scenario outputs

`Output` should show dated price, shares and peer inputs, dividend/distribution valuation with explicit repurchase/share-count handling, residual income with clean-surplus/OCI adjustments, P/B versus ROE and earnings multiples as cross-checks. All cash flows, discount periods and terminal prices share the valuation date. No automatic average or recommendation is produced from unreconciled models. Base/upside/downside cases and catastrophe, reserve, pricing, reinvestment and capital stresses must flow through the integrated statements; insufficient capital cannot be hidden by unlimited buybacks. Regression and Monte Carlo run in Python on documented longer samples/distributions; workbook outputs are versioned snapshots with parameters, seed, run ID and freshness flag, not recalculating random Excel formulas.

2. Version the renderer's child-row map and build operating schedules in the dependency order above. Tie every actual to original source and counterpart schedule, with explicit source-precision tolerances and zero unexplained plugs.
3. Build forecast formulas and integrated three statements, then implement all checks and conditional formatting. A failing required check blocks the approved report/price target.
4. Recalculate in an available spreadsheet engine, compare base/upside/downside workbook values to the Python authority, verify source cells and formula dependencies, and inspect print output. `openpyxl` writing formulas alone is not recalculation. Record any validation tool limitation.
5. Generate workbook, normalized JSON, validation report and research output from one pinned run manifest. Replay must match numeric results and source hashes.

The machine-readable `workbook_contract.json` and `historical_coverage.json` can be regenerated after `python3 scripts/build_historical.py` and `python3 scripts/build_statement_controls.py` with `python3 scripts/build_model_spec.py --inventory examples/travelers/source_inventory.json --actuals examples/travelers/actuals.json --history examples/travelers/historical_actuals.json --statement-controls examples/travelers/statement_controls.json --output-dir docs/model_spec --as-of 2026-02-12`.
