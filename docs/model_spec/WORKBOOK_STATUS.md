# Formula-linked operating workbook

Run `python3 scripts/build_operating_workbook.py` after rebuilding the historical, statement-control, operating and historical-integration JSON. Install the `release` optional dependencies first (`XlsxWriter` and `reportlab`). The script writes `output/travelers_operating_model.xlsx` without Node.js or the Codex workbook package. A verified example release is checked in under `examples/travelers/deliverables/`. `rendered_row_map.json` is the **actual** row/period map for this builder; `workbook_contract.json` remains the broader planning metric catalog.

The workbook has the specified Cover, Summary, Assumptions, Scenarios, Model, Output and Sources tabs. G holds 2019 opening balances, H:M hold audited 2020–2025 actuals, and N:R contain formulas for an **illustrative** 2026–2030 consolidated P&C premium and claims-reserve projection. Historical Model inputs link to individual Sources ledger facts rather than embedding numbers. Historical subtotals, gaps, average invested assets and yields calculate in cells. Source rows carry PDF URL/page/hash, SEC filing date and filing URL. The full historical balance-sheet section has zero asset, liability, equity-component and accounting-equation differences in all seven years. Historical GAAP income has zero revenue, expense, net-income and cash-flow net-income differences in all six flow years. The visible Summary Master Check reads **OPEN: historical stock bridges** while unresolved balances remain.

`Scenarios!D6` is the one live Base/Upside/Downside selector. Changing it changes the same forecast formulas through active Assumptions rows; historical cells remain fixed. `operating_scenarios.json` supplies the editable scenario assumptions, and `scripts/build_operating_forecast_reference.py` calculates the Python authority from the sourced 2025 opening state. The builder evaluates nine forecast outputs across five years and all three cases (135 values) against that authority, checks a changed 2028 growth assumption through `Output!D11`, then exports live Excel formulas with Base-case cached values. The Output tab also links the selected scenario, 2030 earned premium, net reserves, illustrative combined ratio and historical bridge status. The cases hold the FY2025 operating perimeter constant and **exclude the January 2, 2026 Canadian disposal**. They are analyst illustrations, not Travelers guidance or calibrated market forecasts. The workbook does not contain an integrated forecast income statement, balance sheet, cash-flow statement, segment projection, capital constraint, valuation or price target. Historical earning, DAC, investment and debt differences remain visible on Model and are not fed forward as balancing entries. See [historical integration](HISTORICAL_INTEGRATION.md) for the transaction boundary.

The generated formulas and Base-case caches are evaluated in Python during the build. All three scenario outputs and a changed assumption are checked against the source-linked formula graph, and key forecast metrics are compared with the independent Python forecast. A native Excel or LibreOffice recalculation has **not** been performed because no such engine was available in the execution environment; native-app interactive and print behavior remain a validation gate.
